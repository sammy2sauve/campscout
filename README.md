# CampScout

A data pipeline + map dashboard for finding open, well-matched federal
campsites — availability, weather, amenities, and wildlife/terrain context
in one place, instead of five browser tabs.

See [`PROBLEM_STATEMENT.md`](./PROBLEM_STATEMENT.md) for the full problem
definition and scope, and [`CLAUDE.md`](./CLAUDE.md) for architecture/stack
decisions and working conventions.

## Status

🚧 Scaffolding — no pipeline code yet.

## Stack

Python (Prefect orchestration) · PostgreSQL/PostGIS · FastAPI · React + Leaflet
